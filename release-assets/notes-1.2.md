# Munhana 1.2

- Everything is written as maths, never as code: `√`, `∛`, `π`, `x²`, `x₁`,
  `≤`, `≥`, `|x|`, `⌊x⌋`. Function keys insert the symbols directly, and the
  equation editor, the list and exports all show the written form.
- Keyboard rebuilt like a pocket calculator: a template column, a symbol
  column, a 3x4 number pad and an operator column, plus tabs for comparison,
  functions, trigonometry, calculus, symbols and variables.
- Settings cleaned up and made practical: inequality shading is now **off by
  default**, auto-fit can be disabled, the manual window has x/y labels, and
  the panel shows the version and "Built with AI".
- Auto-fit frames all curves whenever an equation is added, edited, deleted or
  imported; pan and zoom remain fully manual afterwards.
- Thin, crisp curve strokes (1.7dp, no halo) so curves stay sharp.
- Download without a VPN from Syria: jsDelivr, Statically and GitHub Pages
  mirrors for 1.2, 1.1 and 1.0 (see the README table).
- APK: `munhana-1.2.apk`

# منحنى 1.2

- كل شيء يُكتب رياضيات لا شيفرة: `√`، `∛`، `π`، `x²`، `x₁`، `≤`، `≥`،
  `|x|`، `⌊x⌋`. مفاتيح الدوال تُدرج الرموز مباشرة، ويظهر ذلك في المحرّر
  وفي القائمة وفي التصدير.
- لوحة المفاتيح أُعيد بناؤها على نمط الآلة الحاسبة: عمود قوالب، عمود رموز،
  لوحة أرقام ٣×٤، وعمود عمليات، مع تبويبات للمقارنة والدوال والمثلثات
  والتفاضل والتكامل والرموز والمتغيرات.
- الإعدادات نُظّفت وأصبحت عملية: **تظليل المتباينات معطّل افتراضيًا**،
  ويمكن إيقاف الملاءمة التلقائية، ومدى العرض موضّح بمحورَي x و y، ويعرض
  أسفل النافذة رقم الإصدار وعبارة «صُنع بالذكاء الاصطناعي».
- ملاءمة تلقائية تُظهر كل المنحنيات عند إضافة معادلة أو تعديلها أو حذفها أو
  استيرادها، ويبقى التكبير والتحريك بيدك بعد ذلك.
- خطوط رفيعة وواضحة (1.7dp، بلا هالة) لتبقى المنحنيات حادة.
- التحميل بدون VPN من سوريا: روابط jsDelivr و Statically و GitHub Pages
  للإصدارات 1.2 و 1.1 و 1.0 (جدول في README وصفحة التحميل).
- ملف التثبيت: `munhana-1.2.apk`
