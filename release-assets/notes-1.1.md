# Munhana 1.1

- Full-screen equation editor with live graph preview.
- Math keyboard with five categories and automatic bracket closing.
- Extended function library, graph settings, PNG/TXT export, share and import.
- Offline image OCR with manual correction for every line.
- APK: `munhana-1.1.apk`
