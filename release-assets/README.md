# Release assets

- `munhana-1.0.apk` — first release.
- `munhana-1.1.apk` — current release: full equation editor, math keyboard,
  graph settings, export/import and improved offline OCR.

Both files are signed with the author's key, so 1.1 installs as an update over
1.0. Verify integrity with `SHA256SUMS.txt`.

الملفان موقّعان بمفتاح المؤلف، لذا يُثبَّت 1.1 كتحديث فوق 1.0. تحقق من السلامة
